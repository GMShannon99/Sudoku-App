How to Play Sudoku

Sudoku is played on a 9×9 grid divided into nine 3×3 boxes. The goal is to fill every empty square so that each row, each column, and each 3×3 box contains every digit from 1 to 9 exactly once — no digit ever repeats within the same row, column, or box.

Every puzzle starts with a handful of givens (or clues): squares that are already filled in and can't be changed. Every other square starts out empty and is yours to work out and fill in.

The most basic solving technique is elimination: a square can only hold a digit that isn't already used somewhere else in its row, its column, or its 3×3 box. Solving a puzzle usually means repeatedly narrowing down each empty square's possibilities until only one digit can legally go there.

Easier puzzles can be fully solved with elimination alone. Harder ones eventually stall — every remaining empty square still has more than one possible digit — and need deeper logical techniques, or educated trial and error (trying a digit, following where it leads, and backing out if it creates a contradiction), to finish.

Sudoku Web Functionality

Starting from a blank grid

When the grid is blank — either the first time the page loads, or right after clicking “Manual Entry” or “New/Clear” — you're on the puzzle entry screen. Type a digit into every square you want as a starting clue and leave every other square blank (no need to type 0 anywhere). Every digit you type is checked against that cell's row, column, and 3x3 box — a digit that's already used elsewhere in that row, column, or box is rejected with a beep. Then either:

  • Click “Start Solving” to lock in whatever you typed as the puzzle's givens and move to the solving screen, or
  • Click “Use Sample Puzzle” to skip straight to the built-in sample puzzle instead, ignoring anything you typed, or
  • Click “Paste Puzzle” to load a puzzle record off the system clipboard — see “Pasting a saved puzzle” below, or
  • Pick a difficulty (Easy, Moderate, or Hard) and click “Generate Puzzle” to create a brand new puzzle instead of typing or pasting one, or
  • Click “Manual Entry” to clear every square on this entry screen and start manually typing a brand new puzzle.

Generating a new puzzle

Next to “Use Sample Puzzle,” a set of difficulty radio buttons (Easy, Moderate, Hard) and a “Generate Puzzle” button let you create a brand-new, randomly generated puzzle instead of typing or pasting one in. Pick whichever difficulty you want first, then click “Generate Puzzle” — if you click it without picking a difficulty, it defaults to Moderate and generates anyway rather than making you choose. Every generated puzzle is guaranteed to have exactly one valid solution. Generating can take a moment, since finding a puzzle at the right difficulty may need several internal attempts — a “Generating puzzle…” message lets you know it's working. Once generation finishes, you're taken straight to the solving screen with the new puzzle loaded, same as clicking “Use Sample Puzzle.”

Pasting a saved puzzle

“Paste Puzzle” loads a puzzle record from the clipboard: a single line of 81 grid digits (0-9, row by row, one digit per cell, 0 for blank), optionally followed by one more character. This is the same record format the desktop Sudoku Solver app's “Save to File” button writes to Sudoku_Save.txt, so a record copied from there pastes in here too. If the clipboard holds a valid record, you're taken straight to the solving screen with that puzzle loaded and ready to solve. If the clipboard doesn't hold a single valid record (wrong length, stray characters, more than one line copied, etc.), an error message explains this and nothing on screen changes. If the record parses but the puzzle itself turns out unsolvable, a red “Pasted puzzle is not valid.” message appears instead.

Row numbers (right side)

The numbers shown to the right of each row list every digit still missing from that row. As you fill in cells, digits drop out of this list. A row that's completely and correctly filled shows a checkmark.

Column numbers (below each column)

The numbers shown below each column work the same way, but for that column: every digit still missing from it, updating live as you play. A fully and correctly filled column shows a checkmark.

Given clues vs. your entries

The puzzle's starting clues are shown in a darker, locked square and cannot be changed — these are the numbers the puzzle began with. Every other cell is yours to fill in and stays editable until the puzzle is solved.

The buttons on the solving screen

  • Save — Takes a snapshot backup of the grid exactly as it looks right now (givens plus whatever you've typed in so far). Each Save adds another backup. This is an in-memory backup only — it's lost when the page is closed or reloaded.
  • Solve — Runs the full solver and fills in every remaining empty cell to complete the puzzle. The same thing happens automatically if you fill in the last empty square yourself. Either way, every square you filled in flashes yellow and stays that way — clicking around or pressing keys won't clear it — until the puzzle actually changes, via Reset, Undo, or New/Clear. The Solve button itself also breaks apart and disappears on a successful solve, with a synthesized glass-breaking sound, leaving its spot empty until the puzzle is no longer solved (Reset, an Undo that reopens the puzzle, or starting a new one) — purely cosmetic, and both the animation and its sound are skipped if your browser's reduced-motion setting is on.
  • Print — Generates a printable image of the puzzle exactly as it currently stands: given clues shaded with a light grey background, your entries on a plain background, the same row/column missing-digit numbers shown on screen, and every empty square's remaining valid candidates laid out in a small grid so it can be worked on with pen or pencil — then opens your browser's print dialog directly with that image, with no file to find first. On a phone, this is the same Share Sheet / print flow (e.g. AirPrint on iOS) any other app's print button would open. If the current entries have no valid solution at all, a popup explains this instead, and nothing is generated.
  • Reset — Restores the most recently saved backup. If you've never clicked Save, this instead clears the grid back to the original puzzle's clues.
  • Help — Opens this help window.
  • New/Clear — After asking you to confirm, discards the current puzzle and every saved backup and takes you back to the blank puzzle entry screen, so you can start over with a brand new puzzle.

Undo (Ctrl+Z)

On the solving screen, pressing Ctrl+Z (or Cmd+Z) undoes your most recent move — whether you typed the digit directly or filled it in by clicking a candidate number — clearing that square again. Pressing it again steps back through your earlier moves one at a time, most recent first.

Difficulty level

Once a puzzle is loaded onto the solving screen, a “Difficulty Level” line appears above the grid: Easy, Moderate, or Hard, based on how many backtracking guesses the solver needed for this exact puzzle.

Puzzle stats

The “View Puzzle Stats” button below shows a live hit count right here, shared with the sudoku-web site so both surfaces count toward one combined total. This button is the only place in the app where that count is ever shown; it stays hidden otherwise. Clicking it also breaks the button itself apart with a synthesized glass-breaking sound (both the animation and the sound are skipped under reduced motion).

Special View Help

The Special view magnifies one of the puzzle's nine standard 3×3 boxes at a time, so its cells and their candidates are much easier to see and pick from than the small squares on the main board.

Filled cells

A cell that already has a value — a given clue or a guess you've already entered — shows that value, styled exactly the same way it is on the main board (given clues shaded darker, guesses plain). A given clue isn't clickable here, same as on the main board. A guess, though, can be clicked to clear it back to empty, immediately showing that cell's candidates again (recalculated fresh, since removing a guess can legalize digits that weren't valid a moment ago) so you can pick a different one the normal way.

Empty cells

An empty cell shows every digit that's still legally allowed there right now, laid out in a small grid inside the cell. Click the cell itself to select it — it turns yellow, exactly like selecting a cell on the main board does — and its candidate digits become clickable. Click one to fill it in; the puzzle updates immediately, the same as if you'd picked that candidate on the main board.

Next / Prior

Next and Prior move to the next or previous of the nine boxes, in reading order (left to right, top to bottom). Prior disappears on the first box, and Next disappears on the last box, since there's nowhere further to go in that direction — each reappears as soon as you're no longer at that end.

Return

Return closes the Special view and takes you back to the main puzzle screen, with any values you picked here already applied.
